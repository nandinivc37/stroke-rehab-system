# AI-Based Stroke Rehabilitation System

A computer vision–based rehabilitation system that assists stroke patients in performing upper-limb exercises using real-time human pose estimation and movement quality assessment.

## Project objective

This project aims to provide objective rehabilitation feedback without requiring wearable sensors or EEG. Using MediaPipe Pose, the system estimates body landmarks, calculates joint angles, detects compensatory movements, and evaluates exercise quality.
